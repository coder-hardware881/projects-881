# Projects 881
Personal website built to demo my coding projects
- ### Hypocycloid:  
   it draws hypocycloids, the curve that emerges when a point on a circle that is rolled inside another circle is traced
   i got the idea to make this when i saw spirographs which work exactly in the same way
   even features a mode that animates the process with controllable speed
   is pretty fast but causes some lag on mobile
